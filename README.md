# Vilar Resident Hub

Create a clean, modern web app shell for **Vilar** (Canadian Multi-Residential Building OS) using React, Tailwind, and local mock data only (no Supabase/backend).

Design & Layout Rules (Strict):

- Palette: Deep Architectural Navy (`#091429`) and Electric Lime Green (`#5FB400`), Outfit font, crisp Light/Dark mode toggle.

- Active Building Header: **The Grove — 217 Units (London, ON)**.

- Navigation: Clean bottom-docked navigation bar on desktop & mobile (matching modern mobile-first ergonomics) with 4 tabs: `Overview`, `Work Orders`, `OpenLobby AI`, and `Inspections`.

- Build ONLY the `Overview` tab in this first step: 4 KPI cards (`Occupancy 98.2%`, `Open Work Orders: 7`, `Deliveries Today: 34`, `After-Hours Resolved: 12`), a compact live activity feed, and a quick-action bar. Keep code modular and lightweight.
